快速开始

准备阶段不要求 QIIME2。打开终端启动服务，然后在页面里完成一键流程：

python qiime2_auto.py serve

打开 http://127.0.0.1:8765 后，按“数据 → metadata → 环境 → 一键分析”操作。页面不会要求你复制命令。

目标分析环境是 Linux + Conda + QIIME2；没有 QIIME2 时，Linux 页面会显示一键安装助手。

python qiime2_auto.py --help
python qiime2_auto.py scan /path/to/raw_data
python qiime2_auto.py serve

然后打开 http://127.0.0.1:8765。控制台会按“数据 → metadata → 环境 → 一键分析”引导你。默认只监听本机。

命令行接口

生成 manifest

python qiime2_auto.py -i raw_data -o prepared --generate-manifest --paired-end

单端数据将 --paired-end 换成 --single-end。

查询 Conda 环境

python qiime2_auto.py envs
python qiime2_auto.py envs --no-probe

生成 QIIME2 安装命令

python qiime2_auto.py install --version 2024.10 --distribution amplicon

生成 metadata

python qiime2_auto.py -i prepared/manifest.tsv -o prepared \
  --generate-metadata --metadata-columns group timepoint

请编辑生成的 TSV，把占位分组改成真实值。sample-id 或 QIIME2 常见的 #SampleID 都支持。

执行分析

python qiime2_auto.py -i prepared/manifest.tsv -o results \
  --metadata prepared/metadata.tsv \
  --classifier /path/to/classifier.qza \
  --sampling-depth 10000 \
  --primer-f GTGCCAGCMGCCGCGGTAA \
  --primer-r GGACTACHVGGGTWTCTAAT
真正执行分析时必须在你自己的 QIIME2 环境中运行。使用 --dry-run 可以只打印命令，不调用外部工具。

支持的输入格式

类型识别方式说明
EMP singlebarcodes.fastq.gz + sequences.fastq.gz单端 EMP
EMP pairedbarcodes + forward + reverse双端 EMP
CasavaSampleA_S1_L001_R1_001.fastq.gz双端需同时存在 R1/R2
manifest任意后缀，内容含 sample-id 与 filepath 列按内容识别；paired-end 会统计引用的所有 FASTQ
混样 FASTQ文件名含 _R1 或普通 FASTQ必须传 --barcodes

picker 选择

Web 控制台支持一次选择多个 FASTQ，也支持先选择 manifest、再选择序列文件；两次选择会合并到同一个数据包。分类器 .qza 和 metadata 也都有 picker，大文件可以直接填写 Linux 服务器路径。

采样深度

页面提供“自动推荐”和“我来定义”。自动推荐会根据每个样本的有效序列量选择共同深度，适合第一次分析；自定义模式输入正整数，例如 10000，不要高于大多数样本的测序深度。

metadata 最小示例

sample-id    group
sample01     control
sample02     treatment

实际 TSV 中不要保留示例前的 + 符号；这里仅用于避免 HTML 排版误读。

环境边界

Python 3.9+ 足以运行帮助、扫描、manifest、metadata 和 Web 控制台。真正分析只在 Linux + Conda + QIIME2 中执行。

控制台会执行 conda env list，逐个检查 qiime --version，让你选择真正可用的环境，并通过 conda run 执行分析。没有可用环境时，Linux 页面提供版本、分发版和环境名选择，并支持一键安装。

完整分析仍需要对应版本的插件、分类器 .qza，以及可选的 Figaro/biom。Windows 仅用于当前开发和前置准备，不能执行 Linux QIIME2 分析。

常见问题

metadata 校验失败怎么办？

检查第一列是否为 sample-id/#SampleID，ID 是否重复，是否有空值，以及是否至少存在一个分组列。

为什么 manifest 显示 0 个 FASTQ？

新版会读取 manifest 的 filepath 列，不再只看 manifest 文件本身。先选择 manifest、再选择对应 FASTQ 时，两次上传会合并到同一个数据包，并自动把跨机器路径映射到当前服务器文件。

为什么 auto 采样深度没有结果？

自动计算需要 QIIME2 导出的 feature table 和 biom。没有 biom 时，可以在页面切换到“我来定义”，输入正整数。

能否只使用 Web？

可以。Linux 服务器准备好环境后，页面会完成环境选择、参数校验、后台任务和进度展示，用户只需点击一次“开始完整分析”。CLI 仍然保留用于自动化和排错。
