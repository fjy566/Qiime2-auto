快速开始

准备阶段不要求 QIIME2。打开终端运行：

python qiime2_auto.py --help
python qiime2_auto.py scan /path/to/raw_data
python qiime2_auto.py serve

然后打开 http://127.0.0.1:8765。控制台会按“扫描 → manifest → metadata → 校验 → 命令预览”引导你。默认只监听本机。

命令行接口

生成 manifest

python qiime2_auto.py -i raw_data -o prepared --generate-manifest --paired-end

单端数据将 --paired-end 换成 --single-end。

生成 metadata

python qiime2_auto.py -i prepared/manifest.tsv -o prepared \
  --generate-metadata --metadata-columns group timepoint

请编辑生成的 TSV，把占位分组改成真实值。sample-id 或 QIIME2 常见的 #SampleID 都支持。

执行分析

python qiime2_auto.py -i prepared/manifest.tsv -o results \
  --metadata prepared/metadata.tsv \
  --classifier /path/to/classifier.qza \
  --sampling-depth 10000 \
  --primer-f GTGCCAGCMGCCGCGGTAA \
  --primer-r GGACTACHVGGGTWTCTAAT
真正执行分析时必须在你自己的 QIIME2 环境中运行。使用 --dry-run 可以只打印命令，不调用外部工具。

实际 TSV 中不要保留示例前的 + 符号；这里仅用于避免 HTML 排版误读。

环境边界

Python 3.9+ 足以运行帮助、扫描、manifest、metadata 和 Web 控制台。程序不会在导入模块时强制加载 biom/pandas，也不会在准备阶段检查 QIIME2。

完整分析需要你自行准备 QIIME2、对应版本的插件、分类器 .qza，以及可选的 Figaro/biom。若缺少 qiime，程序会明确报错，不会伪造成功结果。

常见问题

metadata 校验失败怎么办？

检查第一列是否为 sample-id/#SampleID，ID 是否重复，是否有空值，以及是否至少存在一个分组列。

为什么 auto 采样深度没有结果？

自动计算需要 QIIME2 导出的 feature table 和 biom。没有 biom 时，显式传入例如 --sampling-depth 10000。

能否只使用 Web？

Web 控制台可以发起任务并提供状态接口，但页面默认把完整命令展示出来，便于你在 QIIME2 环境中复现和排错。CLI 始终保留。
