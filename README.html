01 · START HERE

两种使用方法，选你顺手的

如果你是第一次做分析，优先使用前端；如果你需要批量运行、写脚本或定位问题，再使用命令行。两种方式调用的是同一套项目逻辑。

WEB · 推荐新手

前端一键工作流

启动本地服务后，后续主要通过按钮和选择器完成，不需要手动拼接分析命令。

  1. 1选择 manifest，或一次选择多个 FASTQ。
  2. 2预览 / 编辑 manifest，再生成或选择 metadata。
  3. 3按样本选择分组，添加 timepoint、site 等列。
  4. 4选择 Conda 环境、分类器和输出目录，点击开始分析。
CLI · 自动化

命令行接口

适合服务器、批处理、定时任务和需要保留完整命令记录的场景。先查看帮助，再按需调用。

python qiime2_auto.py --help
python qiime2_auto.py scan /path/to/raw_data
python qiime2_auto.py serve

下面的“命令行用法”提供 manifest、metadata 和完整分析示例。

不安装 QIIME2 也能准备数据 文件只暂存在当前服务机器 服务默认只监听本机
开发机可以先打开页面、选择文件、编辑表格并运行测试；真正的 QIIME2 分析，以及 QIIME2 / Figaro 一键安装，只在 Linux + Conda 服务器执行。

02 · INPUT

输入文件与 picker

页面支持选择任意后缀的 manifest，也支持一次选择多个 FASTQ。程序按文件内容和文件名识别数据，不会把 manifest 的扩展名当作格式。

类型识别方式说明
EMP singlebarcodes.fastq.gz + sequences.fastq.gz单端 EMP
EMP pairedbarcodes + forward + reverse双端 EMP
CasavaSampleA_S1_L001_R1_001.fastq.gz双端需要同时存在 R1 / R2
manifest single表头含 sample-id 与 absolute-filepath按内容识别，扩展名不限
manifest paired表头含 sample-id、forward-absolute-filepath、reverse-absolute-filepath双端会统计实际引用的 R1 + R2 文件数

选择 manifest 后，页面会读取其中的 filepath 列；如果再选择对应 FASTQ，两次选择会合并到同一个数据包。双端两行样本会显示 4 个 FASTQ 引用，而不是误报为 0 个。

03 · EDITORS

manifest / metadata 都能预览和编辑

manifest 编辑器

可以从零建立单端或双端 manifest，也可以打开已有文件后修改 sample ID、R1 / R2 路径并增删样本。保存时会检查空路径、重复样本和 FASTQ 是否存在，保存成功后会立即把这个文件设为本次分析输入。

metadata 分组器

metadata 编辑器默认提供一个 group 分类列。输入 control、treatment 等组名，勾选属于该组的样本，再点击一次即可创建并分配；删除组只会清空对应单元格，不会删除样本。

常用字段库提供受试者、时间点、采样部位、处理方式、批次、重复编号、年龄、pH 和温度等快捷模板，也可以添加自定义列，并在表头选择 categorical 或 numeric 类型。这些模板不是 QIIME2 强制字段，应按你的研究设计选用。保存后的文件遵循 QIIME2 TSV metadata 形式：

sample-id  group       age
#q2:types  categorical numeric
sample01   control     3
sample02   treatment   8

第一列是样本 ID，其他列是 metadata；普通空单元格表示缺失值。详细规则请参考 QIIME2 官方 Metadata 说明。

metadata 可以暂时不提供。没有 metadata 时仍可做导入、DADA2 和基础物种分类；需要样本信息的多样性分析、采样深度和 ANCOM 会在启动前检查中自动跳过。如果文件没有至少两个完整的 categorical 分组值，只跳过 ANCOM，其他可用步骤仍会执行。

04 · ENVIRONMENT

环境、分类器、Figaro 和输出目录

Conda / QIIME2 环境

控制台会查询服务器上的 Conda 环境，并逐个检查 qiime 版本，让你选择真正可用的环境。分析执行时会直接使用所选环境，不要求你手动激活环境。

如果没有可用的 QIIME2 环境，Linux 页面会显示版本和分发版选择，并提供一键安装入口；不会覆盖已有环境。开发机没有 QIIME2 不影响前端开发和无依赖测试。

官方分类器

分类器卡片提供在线官方资源。默认推荐 SILVA 138 99% 全长分类器，点击下载后会保存到项目的 classifiers 文件夹，并自动作为默认分类器。另有官方 Greengenes 515F / 806R 区域分类器；也可以用 picker 选择本地 .qza。

Figaro 与输出目录

选中 QIIME2 环境后，页面会检查 Figaro 是否安装。缺少 Figaro 时，在对应卡片点击一键安装；如果暂时不需要自动截断建议，也可以选择跳过。输出目录使用服务器目录 picker 选择，程序会自动创建结果子目录。

05 · PARAMETERS

采样深度：自动推荐或自己定义

页面提供两个清楚的选项：选择“自动推荐”时，程序根据样本有效序列量寻找共同深度；选择“我来定义”时，输入正整数，例如 10000。自定义值不要高于大多数样本的测序深度，否则会丢掉较多样本。

第一次使用建议选择自动推荐；如果自动模式提示缺少 QIIME2 导出的 feature table 或 biom，再改用明确的正整数。

07 · CLI

命令行用法

启动 Web 控制台和检查环境

python qiime2_auto.py serve
python qiime2_auto.py envs
python qiime2_auto.py --help

浏览器打开 http://127.0.0.1:8765。envs 会帮助你确认服务器上有哪些 Conda / QIIME2 环境。

生成双端 manifest

python qiime2_auto.py -i raw_data -o prepared --generate-manifest --paired-end

单端数据把 paired-end 改为 single-end；输出会写入 prepared/manifest.tsv。

生成 metadata 模板

python qiime2_auto.py -i prepared/manifest.tsv -o prepared --generate-metadata --metadata-columns group timepoint

生成后可以在前端按样本分组，也可以直接编辑 prepared/metadata.tsv。

执行完整分析

python qiime2_auto.py -i prepared/manifest.tsv -o results \
  --metadata prepared/metadata.tsv \
  --classifier /path/to/silva-138-99-nb-classifier.qza \
  --primer-f GTGCCAGCMGCCGCGGTAA \
  --primer-r GGACTACHVGGGTWTCTAAT \
  --sampling-depth 10000

sampling-depth 也可以写 auto；如果当前环境没有 biom，请改用明确的正整数。需要检查参数但暂时不调用外部工具时，可以追加 --dry-run。

--metadata 是可选的。省略它仍可执行导入、DADA2 和物种分类（需要分类器），但多样性、采样深度和 ANCOM 会按启动前检查自动跳过；补齐 metadata 后重新运行即可恢复。

08 · FAQ

常见问题

为什么 metadata 校验失败？

检查第一列是不是 sample-id 或 #SampleID，样本 ID 是否为空或重复，numeric 列里是否混入文字。普通 metadata 单元格为空是合法缺失值。

为什么 manifest 显示 0 个 FASTQ？

程序会读取 manifest 的 filepath 列，而不是只看 manifest 文件名。请确认路径能在服务器上找到；如果文件来自浏览器，先选择 manifest，再选择对应 FASTQ，页面会自动合并。

可以只使用 Web 吗？

可以。Linux 服务器准备好 Conda / QIIME2 后，页面会完成环境选择、参数校验、后台任务和进度展示，你只需要点击一次“开始完整分析”。CLI 仍保留，方便批处理和排错。

没有 metadata 可以运行吗？

可以。页面会把缺少 metadata 造成的影响写在“本次分析计划”里：导入、DADA2 和基础物种分类仍可执行，多样性、采样深度和 ANCOM 会明确显示为自动跳过。

Windows 能不能直接完成 QIIME2 分析？

本项目的正式分析边界是 Linux + Conda + QIIME2。Windows 可以用于查看页面、准备输入、编辑表格和运行测试；请把真正分析放到符合条件的 Linux 服务器。
